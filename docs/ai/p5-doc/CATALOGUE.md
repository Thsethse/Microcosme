# Catalogue définitif des références P5 — 01 à 81

Inventaire documentaire arrêté au commit main `f5cb1967cef8fa7d0d58c622502cb6f784188e1d`, le 19 novembre 2026. **81 identifiants de référence, pas 81 géométries indépendantes démontrées ni 81 coiffures programmées.** Les rapprochements sont détaillés dans [DOUBLONS.md](DOUBLONS.md). Aucune référence n’est supprimée.

Une case P5 comporte deux illustrations : **G** et **D** désignent leur position dans la case, pas le sexe, un profil ni une version avant/après. Les deux arrangements sont décrits sous le même identifiant ; ils ne gonflent pas artificiellement le total. Les proportions, visages et corps illustrés ne font jamais partie de la cible.

Les identifiants `p5-001` à `p5-081` sont documentaires. Pour 01–18, les identifiants du moteur P4-R1 restent inchangés. Les positions L/C sont comptées depuis le coin supérieur gauche : V1 sur quatre colonnes, P5 sur trois. P5-E v2 réutilise les numéros imprimés 55–63 : ils deviennent 73–81 uniquement dans cet inventaire, avec la provenance conservée. L’utilisateur a confirmé B409… = E v1 et D9BC… = E v2.

**Statuts** : « existante » = déjà présente dans P4-R1 ; « nouvelle » = intention de construction non présente à l’identique dans la base ; « variante » = arrangement, texture, longueur, couleur ou accessoire apparenté ; « doublon potentiel » = différence capillaire insuffisamment établie, à comparer sans accessoires/couleur. Aucun de ces statuts n’autorise une programmation ou une suppression.

Les longueurs sont des observations relatives aux vignettes : une image coupée au buste ne prouve pas une longueur jusqu’à la taille. Les racines masquées par un couvre-chef sont explicitement inconnues. Les thèmes sociaux/culturels sont des indications de présentation de la source et ne limitent aucun personnage.
