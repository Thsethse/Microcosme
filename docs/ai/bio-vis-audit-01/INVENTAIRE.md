# Inventaire exhaustif des 72 références

Les identifiants de programme sont ceux réellement acceptés : les 18 premiers sont des noms historiques, **pas** les alias documentaires p5-001 à p5-018. La numérotation 13–18 suit l’ordre P4 et la correspondance #33. U = choix historique unique ; G/D = vignettes des planches.

Chaque ligne couvre tous les arrangements disponibles. Le socle (style de base / type de calotte) n’est pas la géométrie finale et n’indique pas un retour silencieux à une coiffure par défaut. Les recettes indiquent les primitives, constantes et différences de silhouette réellement produites. Les paramètres universels de tête sont dans [PARAMETRES](PARAMETRES.md).

Niveaux : **Structure unique** = premier témoin d’une macro-structure dans ce classement ; **Variante structurelle** = modifications significatives au sein d’une famille ; **Variante mineure** = modification locale sans changement de macro-structure ; **Doublon visuel** = copie exacte d’un témoin antérieur dans le protocole B. La priorité au premier témoin est une convention d’inventaire, pas une note de qualité. Les fragments et l’inconnu sont explicitement qualifiés. Une géométrie numériquement distincte peut rester une variante mineure.

Les quatre rapprochements quantifiés ont une planche dédiée ; 56-G/61-G est aussi classé mineur après inspection (même petit chignon, deux mèches ajoutées), sans lui attribuer le seuil de quasi-doublon de 95 %. Le reste du classement est une lecture qualitative, pas un tri perceptuel automatique.
