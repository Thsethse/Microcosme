# BIO-STRUCT-T3-A — laboratoire anatomique indépendant

Preview : https://thsethse.github.io/Microcosme/preview/bio-struct-t3-a/

Ouvrir `index.html` avec les huit autres fichiers applicatifs JS/CSS dans le même dossier ; aucun serveur ni installation requis pour le mode local. Sur GitHub Pages, le lien ci-dessus est le mode d'essai iPad.

Comparer M/F/T, toucher une carte pour ses contrôles, changer la vue, activer les superpositions, modifier proportions/volumes et inspecter la trace N1/N2/N3. La fonction de T reste indépendante de sa morphologie. JSON T3-A propre au lot ; pas de migration biologique T2.

Contrat : branche `docs/bio-struct-t3-a-contract`. Documentation et 23 résultats individuels : `docs/bio-struct-t3-a/` sur la branche `codex/bio-struct-t3-a`. Aucune intégration au moteur, fusion ou phase suivante. Validation artistique et essai iPad physique à effectuer par l'utilisateur.
